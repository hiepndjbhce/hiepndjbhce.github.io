Featured Project

🏓 AIoT Table Tennis Technique Analysis System

Smart coaching system combining AI Camera, IMU-enabled racket and wearable health tracker to analyze table tennis techniques and provide personalized training recommendations.

Technologies

  • ESP32 / ESP32-C3
  • IMU Sensors
  • BLE / Wi-Fi
  • Computer Vision AI
  • Dashboard Analytics

Main Features

  • Stroke detection
  • Swing trajectory analysis
  • Posture recognition
  • Heart-rate monitoring
  • Training recommendations
